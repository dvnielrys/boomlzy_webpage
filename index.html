El Desafío

Dominando el
Microclima Indoor.

Cultivar especies delicadas a nivel comercial o investigativo requiere más que un simple invernadero. Requiere aislamiento y precisión algorítmica.

El Proyecto Bloomly nace con el objetivo de desacoplar el cultivo de las variables meteorológicas externas. Creamos un entorno cerrado donde la temperatura, la humedad relativa y la ventilación no son producto del azar, sino variables matemáticas controladas en tiempo real.

Nos enfocamos en especies de alto valor que requieren estrés térmico controlado (como los tulipanes forzados) y estabilización paramétrica estricta (como las orquídeas premium).

Hardware & Software

Arquitectura del Sistema

Integración de electrónica de consumo, microcontroladores y procesamiento matemático para un control ambiental de grado industrial.

Telemetría Core

El cerebro del sistema orquesta la lectura de arreglos de sensores, almacena series temporales en una base de datos local y ejecuta la lógica de control principal mediando mediante scripts.

  • Cronjobs de muestreo (1Hz)
  • Interfaz de control web local

Integración micro Clima

En lugar de usar actuadores genéricos, realizamos ingeniería inversa / integración API con unidades Mini-Split de LG. El sistema inyecta comandos para modular el compresor inverter y los ventiladores de manera inteligente.

  • Control preciso de frigorías
  • Prevención de picos de consumo

Riego y Nebulización

Mantenemos un déficit de presión de vapor (VPD) óptimo mediante micro-aspersores y nebulizadores ultrasónicos accionados por relés de estado sólido. Aumenta la humedad relativa sin encharcar el sustrato.

  • Gotas < 50 micras (Dry Fog)
  • Ciclos cortos de modulación por ancho de pulso

Filtros de Kalman

Los sensores de bajo costo introducen ruido ("jitter"). Aplicamos Filtros de Kalman en el pipeline de datos para estimar el estado real del sistema, filtrando lecturas erróneas y prediciendo tendencias térmicas antes de que ocurran.

  • Suavizado algorítmico de señales
  • Prevención de oscilación de actuadores (PID tuning)
